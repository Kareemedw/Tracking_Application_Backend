# Tracking-Application

Connecting customers and three different departments together

## Summary of how the user's role works in this app

Customer’s role is to track their application, "department A" role - is to create a temporary account for the customer and email or text them the application reference number and temporary login details asking them to personalize it and make it permanent. When the customer makes their account permanent department A will review the application to see if it compliant and send it to "department C" via "department B" if it is compliant, if not compliant it reaches out to the customer and tell them what additional documentation is needed on the application website, "department B" role - is simply to receive and send application between "department A" and "department C", "department C" role - is to do further checks of compliance and approve the application if it is compliant and reach out to the customer on the website if the application is not compliant and request further documentation.
